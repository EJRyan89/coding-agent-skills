# Code of conduct

## Our commitment

Treat everyone who participates in the project with respect. Welcome people regardless of background,
identity, experience, or ability.

## Expected behavior

- Use considerate, constructive language.
- Discuss ideas and behavior respectfully.
- Accept feedback and take responsibility for mistakes.
- Respect privacy and requests to stop unwanted contact.

## Unacceptable behavior

Harassment, threats, discriminatory language, unwelcome sexual attention, personal attacks, and sharing
someone else's private information without permission are unacceptable.

## Scope

This code applies in project spaces and when representing the project publicly.

## Reporting and enforcement

To report unacceptable behavior, contact the repository maintainer privately through a channel they publish.
If none is available, report abuse on GitHub privately to GitHub Support by following
[GitHub's reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Those instructions cover reporting content or users and link to GitHub Support's abuse-reporting form.

Reports to GitHub Support go to GitHub rather than directly to the repository maintainer. GitHub handles
them under its Community Guidelines and Terms of Service.

The maintainer reviews the reports they receive, respects the privacy of those involved, and takes appropriate action.
Actions can include requesting a correction, removing content, or restricting participation. The response
depends on the conduct, its impact, and whether it continues.

The maintainer follows this code in their own participation and enforcement.
